# SchemaCraft 1.0.1

## Changes

- Fixed reported issues
- Improved application stability
- Preserved compatibility with existing Excel files and schemas

## Installation

1. Download the Windows ZIP.
2. Extract it completely.
3. Run `SchemaCraft.exe`.

## Updating an existing installation

Preserve the existing:

- `data/`
- `builder-auth.json`

Replace only the application executable and application assets according to the update instructions.
